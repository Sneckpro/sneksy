# 🚀 Начните здесь!

## Самый быстрый способ запустить приложение:

### 1. Откройте терминал в этой папке

```bash
cd wallet_app
```

### 2. Запустите сервер

```bash
npm start
```

### 3. Откройте в браузере

- **Регистрация клиентов**: http://localhost:3000
- **Админ-панель**: http://localhost:3000/admin
