# 🎯 Возможности системы

## Для клиентов

### 📱 Регистрация
- Простая веб-форма
- Только необходимые данные: имя, фамилия, email, телефон
- Мгновенная выдача карты лояльности
- Уникальный номер карты для каждого клиента

### 💳 Электронная карта
- **Apple Wallet** - для iPhone/Apple Watch
- **Google Wallet** - для Android устройств
- QR-код для быстрой идентификации
- Всегда под рукой в телефоне
- Автоматическое обновление при изменении скидки

### 🎁 Накопительные скидки
- **3%** - сразу при регистрации
- **5%** - после 40,000₽ накоплений
- **10%** - после 100,000₽ накоплений
- **15%** - после 200,000₽ накоплений

### 📊 Прозрачность
- Видно текущую скидку
- Показывает общую сумму покупок
- Информация о следующем уровне скидки

## Для ресторана

### 👥 База клиентов
- Все зарегистрированные клиенты в одном месте
- Email и телефон для связи
- История покупок каждого клиента
- Статистика по накоплениям

### 🔍 Удобный поиск
- По имени
- По email
- По телефону
- По номеру карты

### 💰 Управление транзакциями
- Быстрое добавление покупок
- Автоматический расчет скидки
- История всех операций
- Описание к каждой покупке

### 📈 Автоматизация
- Скидка рассчитывается автоматически
- Карты обновляются без участия клиента
- Уровень повышается при достижении порога
- Не нужно вручную пересчитывать

### 📱 QR-код регистрации
- Единый QR-код для всех клиентов
- Можно распечатать
- Разместить в ресторане
- Отправить в соцсетях

## Сценарии использования

### Сценарий 1: Первый визит клиента

1. Клиент видит QR-код в ресторане
2. Сканирует телефоном
3. Заполняет форму регистрации
4. Получает карту с 3% скидкой
5. Добавляет в Apple/Google Wallet
6. При оплате показывает карту
7. Получает 3% скидку

**Результат**: Клиент зарегистрирован, скидка применена!

---

### Сценарий 2: Постоянный клиент

1. Клиент приходит в ресторан
2. Заказывает на 15,000₽
3. Показывает карту (QR-код)
4. Кассир сканирует → находит клиента
5. В админке добавляет покупку
6. Скидка 5% применяется автоматически
7. Клиент платит 14,250₽
8. Общая сумма покупок увеличивается

**Результат**: Транзакция записана, клиент доволен!

---

### Сценарий 3: Достижение нового уровня

1. У клиента накоплено 95,000₽
2. Текущая скидка: 5%
3. Делает заказ на 10,000₽
4. Скидка 5%: 500₽
5. Платит: 9,500₽
6. Общая сумма: 104,500₽
7. **Система автоматически повышает скидку до 10%!**
8. Карта в телефоне обновляется
9. Клиент получает уведомление на телефон

**Результат**: Клиент мотивирован приходить чаще!

---

### Сценарий 4: Аналитика для ресторана

1. Менеджер открывает админ-панель
2. Видит статистику:
   - Всего клиентов: 150
   - С 3% скидкой: 80 человек
   - С 5% скидкой: 45 человек
   - С 10% скидкой: 20 человек
   - С 15% скидкой: 5 человек
3. Находит самых активных клиентов
4. Может отправить им персональные предложения

**Результат**: Понимание аудитории, рост лояльности!
