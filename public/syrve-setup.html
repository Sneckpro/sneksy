Как работает интеграция

Автоматическая синхронизация заказов:

  1. Клиент делает заказ в Syrve
  2. Syrve отправляет вебхук на ваш сервер
  3. Система автоматически находит клиента по телефону или email
  4. Создается транзакция с суммой заказа
  5. Скидка рассчитывается и применяется автоматически
  6. При достижении нового уровня, карта в телефоне клиента обновляется

Поддерживаемые события:

  • DeliveryOrderUpdate - обновление статуса заказа (обрабатываются закрытые заказы)
  • DeliveryOrderError - ошибки заказа (логируются)

Настройка API:

Добавьте в файл .env:

SYRVE_API_LOGIN=ваш_api_login SYRVE_ORGANIZATION_ID=ваш_organization_id

После изменения перезапустите сервер: npm start
