# Apple Pass Assets

Поместите сюда следующие изображения:

## Обязательные файлы:

1. **icon.png** (58x58 пикселей)
   - Иконка карты, отображается в списке passes
   - PNG формат, без прозрачности

2. **icon@2x.png** (116x116 пикселей)
   - Иконка для Retina дисплеев

3. **logo.png** (320x100 пикселей или меньше)
   - Логотип вашего ресторана
   - Отображается на лицевой стороне карты

4. **logo@2x.png** (640x200 пикселей или меньше)
   - Логотип для Retina дисплеев

## Опциональные файлы:

5. **strip.png** (375x123 пикселей)
   - Полоса-баннер на карте
   - Для типа карты "storeCard" не обязателен

6. **strip@2x.png** (750x246 пикселей)

## Рекомендации:

- Используйте PNG формат
- Не используйте прозрачность для icon.png
- Придерживайтесь указанных размеров
- Для @2x версий используйте удвоенные размеры

## Быстрый способ создать картинки:

Используйте любой онлайн-сервис:
- https://www.canva.com
- https://www.figma.com
- https://www.photopea.com (бесплатный Photoshop онлайн)

Или просто создайте простые цветные квадраты:
```bash
# macOS - создать цветные квадраты через ImageMagick
brew install imagemagick
convert -size 58x58 xc:blue icon.png
convert -size 116x116 xc:blue icon@2x.png
convert -size 320x100 xc:blue logo.png
convert -size 640x200 xc:blue logo@2x.png
```

## Примечание:

Если файлы отсутствуют, Apple Wallet выдаст ошибку при попытке добавить карту.
Для тестирования системы БЕЗ Apple Wallet эти файлы не нужны.
