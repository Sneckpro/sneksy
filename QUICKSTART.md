# Быстрый старт без настройки Wallet (для тестирования)

Если вы хотите протестировать систему лояльности без настройки Apple Wallet и Google Wallet:

## 1. Установите зависимости

```bash
cd wallet_app
npm install
```

## 2. Запустите сервер

```bash
npm start
```

Вы увидите:

```
╔════════════════════════════════════════════════╗
║   Restaurant Wallet System                     ║
║   Сервер запущен на порту 3000                ║
║                                                ║
║   Регистрация: http://localhost:3000/       ║
║   Админ-панель: http://localhost:3000/admin ║
╚════════════════════════════════════════════════╝
```

## 3. Откройте приложения

### Регистрация клиентов
Откройте: http://localhost:3000

Здесь клиенты могут:
- Зарегистрироваться в программе лояльности
- Указать имя, фамилию, email и телефон
- Получить виртуальную карту с начальной скидкой 3%

### Админ-панель
Откройте: http://localhost:3000/admin

Здесь вы можете:
- Видеть всех зарегистрированных клиентов
- Искать клиентов по имени, email или телефону
- Добавлять транзакции (покупки)
- Просматривать историю покупок каждого клиента
- Скачать QR-код для регистрации

## 4. Протестируйте систему

### Шаг 1: Зарегистрируйте клиента

1. Откройте http://localhost:3000
2. Введите данные:
   - Имя: Алексей
   - Фамилия: Смирнов
   - Email: alex@example.com
   - Телефон: +7 999 123 45 67
3. Нажмите "Зарегистрироваться"

Клиент получает карту с **3% скидкой**.

### Шаг 2: Добавьте покупку

1. Откройте http://localhost:3000/admin
2. Найдите Алексея в списке
3. Нажмите "Добавить покупку"
4. Введите сумму: **45000** рублей
5. Нажмите "Добавить"

Что произойдет:
- Скидка 3% будет применена автоматически (1,350₽)
- К оплате: 43,650₽
- Общая сумма покупок: 43,650₽
- **Скидка повысится до 5%** (порог 40,000₽ превышен)

### Шаг 3: Добавьте еще покупки

Продолжайте добавлять покупки и наблюдайте:
- После **100,000₽** → скидка **10%**
- После **200,000₽** → скидка **15%**

## 5. Понимание системы скидок

### Уровни скидок:

| Потрачено      | Скидка |
|----------------|--------|
| При регистрации | 3%     |
| 40,000₽+       | 5%     |
| 100,000₽+      | 10%    |
| 200,000₽+      | 15%    |

### Как работает:

1. Клиент регистрируется → получает 3%
2. Совершает покупки
3. Система считает общую сумму потраченных средств (ПОСЛЕ применения скидки)
4. При достижении порога скидка автоматически повышается
5. Новая скидка применяется ко всем следующим покупкам

### Пример расчета:

```
Покупка: 50,000₽
Текущая скидка: 3%
Скидка в рублях: 1,500₽
К оплате: 48,500₽
Записано в базу: 48,500₽

Общая сумма покупок: 48,500₽
Новая скидка: 5% (т.к. > 40,000₽)
```

## 6. QR-код для регистрации

В админ-панели есть QR-код, который можно:
- Распечатать и повесить в ресторане
- Показать клиентам на экране
- Разместить на сайте

Клиенты сканируют → попадают на страницу регистрации → регистрируются.

## 7. База данных

Все данные хранятся в файле `database.sqlite`.

Вы можете открыть его любым SQLite браузером для просмотра:
- [DB Browser for SQLite](https://sqlitebrowser.org/) (бесплатно)
- [TablePlus](https://tableplus.com/)

В базе две таблицы:
- **users** - пользователи
- **transactions** - все покупки

## 8. Что дальше?

### Для продакшена:

1. **Настройте Apple Wallet и Google Wallet**
   - Следуйте инструкциям в `SETUP.md`
   - Клиенты смогут добавлять карты в телефон
   - Карты будут автоматически обновляться при изменении скидки

2. **Разверните на сервере**
   - Купите VPS (DigitalOcean, Vultr, Timeweb)
   - Настройте домен с HTTPS
   - Запустите через PM2

3. **Добавьте безопасность**
   - Защитите админ-панель паролем
   - Настройте CORS
   - Используйте PostgreSQL вместо SQLite

4. **Расширьте функционал**
   - Отправка email/SMS уведомлений
   - История покупок для клиентов
   - Аналитика и отчеты
   - Экспорт данных
